# UI 与功能验收矩阵

本文件是全站逐页验收的可重复清单。状态只允许：`NOT_RUN`、`PASS`、`FAIL`、`BLOCKED_BY_DATA`、`NOT_AUTHORIZED`。只有真实浏览器证据或覆盖该操作的自动化测试可以把项目改为 `PASS`。

## 验收边界

- 角色：超级管理员、运营管理员、教务、老师。
- 视口：桌面 `1440×900`、窄桌面/平板 `900×900`、手机 `375×900`。
- 每页都必须验证：导航、完整渲染、筛选/标签、列表与详情、弹窗打开/关闭、键盘焦点、整页横向溢出、遮挡、空状态和错误状态。
- 生产巡检不得制造测试垃圾；写操作必须由自动化契约、可丢弃环境或明确批准的测试记录证明。
- `BLOCKED_BY_DATA` 不是完成状态。若操作本身允许无关联资料，UI 必须提供可继续路径；若业务必须依赖权威资料，UI 必须明确说明缺什么并给出可到达的补录入口。

### 本地响应式与导航契约

- `tests/responsive-navigation-contract.test.mjs` 覆盖 900px 取消旧页面最小宽度、紧凑侧栏可收缩、375px“更多”抽屉使用完整角色导航、17 个页面均有 `renderView` 分支，以及 messages/files 在 1210px 以下单栏并只在内部滚动。
- 目标测试共 17 项通过；TypeScript 与相关 ESLint 通过。900px 的 17 页 Ego Lite 实测也已通过；生产发布后仍需对部署版本重复同一巡检，不能沿用本地证据。

### 第一轮修复状态

- 课程页来源按钮已按角色分流：管理员进入 `sync`；普通教务在原页展开当前课程的真实来源证据，不再进入不可授权页面。
- LP 的看板和表格共用可操作空状态；当前筛选为空时明确说明并提供“创建 LP”。
- 批量老师请假/代课/离职的老师与起止日期已与服务端业务校验同步标为必填；从具体课次进入的单节学生请假继续允许不填老师/日期。
- 角色边界已同时收紧前端与 classroom API：普通 staff 不显示也不能手工请求课堂；同名 staff 不能被教师名册误升为老师；管理员与 limited admin 保留授权页面，薪资仍为 Nixon-only；管理员模拟老师视图时不能冒用授课老师身份进入课堂。
- 上述流程、角色、classroom 与响应式目标测试共 45 项通过，TypeScript 通过；发布版本仍需 Ego Lite 复测。

### 排课数据根因

- 只读聚合检查确认当前 `jiaowubao-direct-import/schedule` reader 可返回 `state=complete`，不是 RPC 缺失；当前 2026 窗口事件数为 0。现有 98 条原生 Booking 全部关联历史归档学生且集中在 2026-07-20 至 2026-07-26，因此 Abby 活跃范围的 `scopedBookings=0` 符合现有数据。
- 真正断点是两条数据管道没有连接：30 分钟任务写入 `jiaowubao_open_api_schedule_snapshot_*` 私有快照，而排课页继续读取旧 Excel/direct-import 的 `get_jiaowubao_direct_schedule_window`。Open API 同步成功不会自动出现在排课页。
- 当前修复轮将新增 Open API 快照的范围化只读 reader，并让排课页改读该来源；同时区分会话失效、reader 未部署、服务暂时失败、快照过期和真实空窗口。该项完成前 `schedule` 维持 `BLOCKED_BY_DATA`。

## 交付门槛

1. 17 个页面均不再是 `NOT_RUN`、`FAIL` 或 `BLOCKED_BY_DATA`。
2. 每个角色只能看到被授权页面与记录；权限不足必须是 `NOT_AUTHORIZED`，不能是假空白或越权数据。
3. 所有可写操作有自动化成功证据，或在可丢弃环境完成真实提交与回放验证。
4. 三个视口无整页横向溢出、不可关闭遮罩、焦点落入背景、固定栏遮挡主要按钮等问题。
5. `npm run build`、TypeScript、相关 UI/业务测试通过；任何剩余失败必须被单独修复，不能用“与 UI 无关”作为最终完成理由。
